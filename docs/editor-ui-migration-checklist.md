## 共同验收

- Vue拥有全部现有后台页面DOM；业务控制器与原生Canvas／共同引擎分离。中间批的不透明DOM容器已在UI-13移除。
- 不把服务端权限换成菜单隐藏；保留CSRF、所有权、会话代际、CAS、永久幂等与未知结果纪律。
- 所有作者文本按文本呈现；密码、凭据、完整编辑源与游戏运行对象不进入Vue响应式树。
- 单模块导航、未提交输入／未确认操作离开守卫、浏览器前后退、退出与身份切换清理、迟到回包均须验证。
- 每批复用适用的静态／单元及全新隔离浏览器验证；涉及写入控制器时补对应真实后端流程。重入口串行执行，仅操作自有临时数据，不访问真实SAVE.DAT、实际profile或正式存档。
- 交付前重新核构建逐字节一致、依赖审计、源码语法、diff、支持文件LSP与全量缓存诊断；inconclusive不能记为clean。
- 最终逐项证据见[收尾审计](editor-ui-final-audit.md)。阶段结构真实GET已在追加授权后修复并通过完整回归，全部迁移项已闭合；LSP覆盖限制如实记录，不等于完整编辑器产品或部署完成。未经明确授权不commit、push或部署。
